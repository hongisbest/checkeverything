# Vehicle Sticker Check V7

V6에서 다음 단계인 검사영역(ROI) 설정 기능을 추가한 버전입니다.

## V7에서 추가된 기능
- 관리자 페이지에서 기준사진 선택
- 기준사진 위에서 마우스/터치 드래그
- 스티커 검사영역 사각형 지정
- 검사영역 이름 지정
- 검사영역 좌표를 D1에 비율값으로 저장
- 여러 검사영역 저장 가능
- 검사영역 삭제
- 사용자 화면에서 기준사진 위에 검사영역 표시

## 반드시 해야 할 DB 작업
V6 DB를 그대로 쓰는 경우 Cloudflare D1 Console에서 `migration-v7.sql` 내용을 한 번 실행하세요.
