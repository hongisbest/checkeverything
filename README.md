# 차량 홍보스티커 셀프점검 - 최신 검증 통합본

## 주소
- 직원: `/check/`
- 관리자: `/admin/`

## 포함 기능
- 관리자 로그인
- 정상 기준사진 + 촬영가이드 등록
- 촬영방향별 활성사진 관리
- 기준사진 위 ROI(검증영역) 드래그 지정
- 사용자 실시간 카메라 / 사진 업로드
- 기준사진과 ROI 자동 비교
- 정상 / 확인필요 1차 판정
- 위치 어긋남 / 탈락·큰 훼손 / 변색·오염 / 형상 변화 검증항목 생성
- 사진 및 결과 저장
- 관리자 결과 모니터링
- 개선요청 / 조치완료 관리
- CSV 다운로드

## 데이터 보존
이 버전은 기존 테이블을 건드리지 않고 `vc2_` 접두사의 신규 테이블만 사용합니다.
R2도 `app-v2/reference/`, `app-v2/inspection/` 폴더만 사용합니다.
기존 점검결과와 연결된 기준사진은 삭제를 차단합니다.


## V2 수정사항
- 관리자 점검결과의 사진 클릭 시 전체 화면 확대 모달
- 우측 상단 × 버튼, 배경 클릭, ESC 키로 닫기
- 기존 저장/API/DB 구조 변경 없음
