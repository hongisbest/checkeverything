# 차량 홍보스티커 셀프점검 - 최신 검증 통합본

## 주소
- 직원: `/check/`
- 관리자: `/admin/`

## 포함 기능
- 관리자 로그인
- 정상 기준사진 + 촬영가이드 등록
- 촬영방향별 활성사진 관리
- 기준사진 위 ROI(검증영역) 드래그 지정
- 사용자 실시간 카메라 / 사진 업로드
- 기준사진과 ROI 자동 비교
- 정상 / 확인필요 1차 판정
- 위치 어긋남 / 탈락·큰 훼손 / 변색·오염 / 형상 변화 검증항목 생성
- 사진 및 결과 저장
- 관리자 결과 모니터링
- 개선요청 / 조치완료 관리
- CSV 다운로드

## 데이터 보존
이 버전은 기존 테이블을 건드리지 않고 `vc2_` 접두사의 신규 테이블만 사용합니다.
R2도 `app-v2/reference/`, `app-v2/inspection/` 폴더만 사용합니다.
기존 점검결과와 연결된 기준사진은 삭제를 차단합니다.


## V2 수정사항
- 관리자 점검결과의 사진 클릭 시 전체 화면 확대 모달
- 우측 상단 × 버튼, 배경 클릭, ESC 키로 닫기
- 기존 저장/API/DB 구조 변경 없음


## V4 관리자 판정기준 설정
관리자 `/admin/` → `판정기준 설정`에서 아래 값을 직접 저장할 수 있습니다.
- 정상 허용 손상률
- 교체권고 손상률
- 위치 허용오차
- 허용 색상차이
- 최소 형상 유사도
- 각 검사항목 사용/미사용

저장한 값은 D1의 `vc2_rules` 테이블에 저장되며 다음 신규 점검부터 즉시 반영됩니다.
코드 수정이나 재배포가 필요하지 않습니다.

주의: 현재 '손상률'은 이미지 비교 형상차이에서 계산하는 추정값이며 실제 물리적 면적을 직접 계측한 값은 아닙니다.


## V5 기준사진 수정
기준사진 목록에 `수정` 버튼이 추가되었습니다.

수정 가능 항목:
- 기준사진명
- 촬영방향
- 촬영가이드
- 기준사진 파일(선택사항)

데이터 보존 정책:
- 사진을 바꾸지 않으면 기존 행의 설정만 수정합니다.
- 아직 점검에 사용되지 않은 기준사진은 사진 파일도 안전하게 교체합니다.
- 이미 점검결과와 연결된 기준사진의 사진을 바꾸면 기존 기준사진을 덮어쓰지 않고 새 버전을 생성합니다.
- 새 버전에는 기존 검증영역(ROI)을 복사합니다.
- 과거 점검결과는 과거 기준사진 ID를 계속 참조합니다.
