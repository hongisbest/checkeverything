# Vehicle Sticker Check V6

관리자가 정상 기준사진을 등록하고, 사용자는 해당 사진을 자동으로 받아 촬영하는 첫 full-stack 테스트 버전입니다.

## URL
- 사용자: `/check/`
- 관리자: `/admin/`

## Cloudflare 구성
- Workers: 웹앱/API
- D1: 기준사진 메타데이터
- R2: 실제 이미지 파일
- Worker Secret:
  - `ADMIN_PASSWORD`
  - `ADMIN_SESSION_SECRET`

## 주요 기능
### 사용자
- 기준사진 직접 업로드 기능 제거
- 관리자가 활성화한 기준사진 자동 로드
- 기준사진 반투명 오버레이
- 실시간 카메라 촬영
- 화면 배율/오버레이 투명도 조절

### 관리자
- 비밀번호 로그인
- 기준사진 등록
- 촬영방향 선택
- 기준사진 목록
- 활성사진 지정
- 삭제

## 다음 단계(V7)
- 기준사진 위에서 스티커 검사영역(ROI) 드래그 지정
- ROI 좌표 D1 저장
- 사용자 촬영사진 위치 정렬
- 기준 ROI와 촬영 ROI 차이값 계산
