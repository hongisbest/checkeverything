# Vehicle Sticker Check V2

법인차량 홍보스티커 셀프점검 시스템의 카메라 테스트 버전입니다.

## V2 기능

- 정상 기준사진 선택
- 브라우저에서 실시간 카메라 실행
- 모바일 후면 카메라 우선 요청
- 전면 / 후면 카메라 전환
- 기준사진을 카메라 화면 위에 반투명 오버레이
- 오버레이 투명도 조절
- 웹페이지 안에서 사진 촬영
- 기준사진 / 촬영사진 비교 표시
- 서버 저장 없음

## 중요

웹 카메라 API(getUserMedia)는 보안 연결(HTTPS)에서만 정상 작동합니다.

Cloudflare의 `https://...workers.dev` 또는 연결한 HTTPS 도메인에서 테스트하세요.

## 권한 오류가 날 때

### iPhone / Safari
설정 → Safari 또는 해당 웹사이트 설정 → 카메라 → 허용

### Android / Chrome
Chrome → 사이트 설정 → 카메라 → 해당 사이트 허용

다른 앱이 카메라를 사용 중이라면 카메라 접근이 실패할 수 있습니다.
